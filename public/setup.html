VK Remote

Эту страницу можно закрыть, когда всё зелёное. Сервер работает, пока открыто чёрное окно.

  1. Поставь расширение Tampermonkey в браузер, где ты слушаешь VK:
    Chrome / Яндекс / Opera Edge Firefox
  2. Разреши ему запускать скрипты (Chrome, Edge, Яндекс):
    открой chrome://extensions (в Edge — edge://extensions) → включи «Режим разработчика» справа сверху → у Tampermonkey нажми «Сведения» и включи «Разрешить пользовательские скрипты», если такой переключатель есть.
    В Firefox этот шаг не нужен.
  3. Установи скрипт пульта — Tampermonkey откроет окно, нажми «Установить»:
    Установить скрипт
  4. Открой VK в этом же браузере и включи любой трек:
    Открыть vk.com/audio
    Жду вкладку VK…
    Если долго жёлтое — обнови вкладку VK (F5) и проверь шаги 2–3.
Пульт на телефоне

Наведи камеру телефона (тот же Wi-Fi), открой ссылку и добавь её на главный экран.

Открыть пульт на этом ПК

Телефон не открывает ссылку? Значит, при первом запуске Windows-брандмауэр заблокировал Node.js: «Панель управления → Брандмауэр → Разрешить взаимодействие с приложением» → поставь галочку «Частная» у Node.js.
