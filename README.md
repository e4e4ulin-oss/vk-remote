# VK Remote — пульт для музыки ВК с телефона

Переключать треки, ставить на паузу, искать и включать музыку из «Моей музыки» на ПК, не вставая с дивана.

```
телефон (браузер, Wi-Fi) ──► server.js на ПК ◄── юзерскрипт во вкладке vk.com
```

Официального API для музыки ВК у сторонних приложений нет, поэтому управление идёт через **вкладку vk.com в браузере на ПК**: юзерскрипт сам нажимает кнопки VK.
Если вкладка не на связи, ⏮ ⏯ ⏭ всё равно работают через системные медиаклавиши Windows.

## Самый простой способ — один файл (для друзей)

Отправь человеку файл **`Установить пульт VK.bat`** (он лежит в корне репозитория). Он один раз его запускает, и всё:

1. Bat скачивает Node.js и программу в `%LOCALAPPDATA%\VKRemote`. Права администратора не нужны.
2. Windows один раз спросит «Разрешить изменения?» — нажать **«Да»**: это правило брандмауэра, чтобы телефон достучался до ПК.
3. На рабочем столе появляется ярлык **«Управлять музыкой через ВК»**, и он сразу срабатывает.

Ярлык открывает **отдельное окно Яндекс Браузера** (если его нет — Chrome или Edge) с VK и страницу с QR-кодом.
В первый раз в этом окне нужно войти в VK, дальше вход сохраняется. Телефон сканирует QR — и пульт готов.

Расширения не нужны: сервер управляет окном напрямую, через протокол отладки браузера (`browser.js`).
Окно запускается со своим профилем (`%LOCALAPPDATA%\VKRemote\browser-profile`), основной профиль браузера не трогается.
В этом окне звук включается без клика мышью.
Если окно закрыли, на телефоне появится кнопка «Открыть VK на компьютере».

Повторный запуск bat-файла обновляет программу до последней версии; ключ (ссылка для телефона) и вход в VK сохраняются.

## Как скачать

https://github.com/e4e4ulin-oss/vk-remote → зелёная кнопка **Code** → **Download ZIP** → распакуй в любую папку.

## Запуск — двойной клик по `VK-Remote.bat`

Bat-файл сам:
- скачает портативный Node.js в папку `runtime` (только при первом запуске, без админ-прав, ~30 МБ);
- создаст ярлык «VK Remote» на рабочем столе;
- запустит сервер **в фоне, без окна** и откроет в браузере `http://127.0.0.1:27613/setup`.

Повторный клик по ярлыку, когда сервер уже работает, просто открывает эту страницу.
Остановить сервер: ссылка «Остановить сервер» на странице или `VK-Remote-stop.bat`. После перезагрузки ПК — снова ярлык.
Лог сервера: `runtime\server.log`.

На этой странице — пошаговая настройка, QR-код для телефона и индикатор «вкладка VK на связи».
Один раз вручную, по кнопкам на странице:
1. Поставить расширение **Tampermonkey** (браузер не даёт поставить расширение из bat-файла).
2. В Chrome/Edge/Яндексе: `chrome://extensions` → «Режим разработчика» → у Tampermonkey «Разрешить пользовательские скрипты».
3. Нажать «Установить скрипт».

Дальше каждый раз: ярлык на рабочем столе → открыть vk.com → пульт на телефоне по QR (добавь его на главный экран).
При первом запуске Windows спросит про брандмауэр для Node.js — разреши для **частных сетей**, иначе телефон не достучится.

## Что умеет

- ⏮ ⏯ ⏭, громкость, перемотка
- «Моя музыка» — список твоих треков, тап по треку включает его на ПК
- «Поиск» — поиск по музыке VK
- «С экрана ПК» — забрать список с текущей открытой страницы (плейлист, альбом и т.п.)
- «Загрузить ещё» — докрутить список вниз

## Если что-то не работает

**Сервер не запускается, в логе «Порт 27613 уже занят».** Порт занят другой программой. Узнать какой:
`netstat -ano | findstr :27613` → последнее число — PID → найди его в Диспетчере задач на вкладке «Подробности».
Порт меняется в трёх местах: `PORT` в `server.js`, `SERVER` и `@updateURL`/`@downloadURL` в `vk-remote.user.js`, ссылка `/setup` в `VK-Remote.bat`.


VK часто меняет вёрстку, а проверить скрипт на живом vk.com без аккаунта я не мог.
Если список пустой или трек не включается: открой на ПК раздел музыки, на телефоне нажми **«Диагностика»** и пришли текст.
По нему подстраиваются `ROW_SELECTORS`, `MY_MUSIC_PATH` и `SEARCH_PATH` в начале `vk-remote.user.js`.

## Безопасность

- Пульт открывается только по ссылке с ключом (`config.json`, создаётся при первом запуске; удали файл — будет новый ключ).
- Юзерскрипт подключается к серверу только с `127.0.0.1`.
- Сервер слушает локальную сеть. Не пробрасывай порт 27613 в интернет.
