# VK Remote — пульт для музыки ВК с телефона

Переключать треки, ставить на паузу, искать и включать музыку из «Моей музыки» на ПК, не вставая с дивана.

```
телефон (браузер, Wi-Fi) ──► server.js на ПК ◄── юзерскрипт во вкладке vk.com
```

Официального API для музыки ВК у сторонних приложений нет, поэтому управление идёт через **вкладку vk.com в браузере на ПК**: юзерскрипт сам нажимает кнопки VK.
Если вкладка не на связи, ⏮ ⏯ ⏭ всё равно работают через системные медиаклавиши Windows.

## Установка (один раз)

1. Поставь [Node.js](https://nodejs.org) (LTS).
2. В браузере на ПК поставь расширение **Tampermonkey**.
   В Chrome/Edge в настройках расширения включи **«Разрешить пользовательские скрипты»** (Allow User Scripts), иначе скрипт не запустится.
3. Открой `vk-remote.user.js` → Tampermonkey предложит установить → «Установить».
   (Или: Tampermonkey → «Создать скрипт» → вставь содержимое файла → сохрани.)

## Запуск

1. Двойной клик по `start.bat` (или `node server.js`).
   При первом запуске Windows спросит про брандмауэр — разреши для **частных сетей**.
2. Сервер напечатает ссылку вида `http://192.168.x.x:8765/?k=…` — открой её на телефоне (тот же Wi-Fi) и добавь на главный экран.
3. На ПК открой vk.com (вкладка может быть в фоне). Индикатор на телефоне станет зелёным: «ПК на связи».

## Что умеет

- ⏮ ⏯ ⏭, громкость, перемотка
- «Моя музыка» — список твоих треков, тап по треку включает его на ПК
- «Поиск» — поиск по музыке VK
- «С экрана ПК» — забрать список с текущей открытой страницы (плейлист, альбом и т.п.)
- «Загрузить ещё» — докрутить список вниз

## Если что-то не работает

VK часто меняет вёрстку, а проверить скрипт на живом vk.com без аккаунта я не мог.
Если список пустой или трек не включается: открой на ПК раздел музыки, на телефоне нажми **«Диагностика»** и пришли текст.
По нему подстраиваются `ROW_SELECTORS`, `MY_MUSIC_PATH` и `SEARCH_PATH` в начале `vk-remote.user.js`.

## Безопасность

- Пульт открывается только по ссылке с ключом (`config.json`, создаётся при первом запуске; удали файл — будет новый ключ).
- Юзерскрипт подключается к серверу только с `127.0.0.1`.
- Сервер слушает локальную сеть. Не пробрасывай порт 8765 в интернет.
